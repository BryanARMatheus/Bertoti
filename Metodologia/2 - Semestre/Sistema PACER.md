## 1. Descrição do Projeto

O projeto desenvolvido no segundo semestre de 2025 consistiu no desenvolvimento de um sistema PACER(Proatividade, Autonomia, Colaboração, Entrega de Resultados), este por sua vez tem como objetivo servir como ferramenta de avaliar soft skills entre membros do grupo.

### 1.1 Objetivo Geral

Desenvolver uma aplicação que facilite e agilize o processo de adquirir os pontos para o sistema pacer, calcular a media individual de cada aluno dos grupos, considerando todos os votos do grupo sobre aquele aluno, guardar estes dados em um banco de dados MySQL.

### 1.2 Objetivos Específicos

- **Centralização de Dados**: Permitir o acesso a dados espalhados em um local centralizado
- **Preencher a pesquisa PACER**: O aplicativo disponibiliza uma opção aos alunos para responder questionários de sua própria equipe e enviar diretamente ao banco de dados.
- **Visualização rápida de Dados**: Providenciar uma tela ao professor para visualizar de forma facil as médias e avaliações de todos os alunos de uma determinado grupo.
- **Importação de dados de avaliações em formato .csv**: O programa tem capacidade de importar dados de arquivos em formato .csv e inserir diretamente no banco de dados
- **Geração de relatórios**: Gerar relatórios com as médias dos alunos para fácil visualização e utilização posterior por parte do professor.

## 2. Tecnologias Utilizadas

### Java | JavaFX
Java foi utilizado para toda a lógica do programa, por conta de sua robustez, tipagem estática e forte orientação a objetos.
Também foi utilizado JavaFX para a construção da Interface resposiva do projeto, afim de tornar o programa navegavel e intuitivo.

### MySQL
Fora utilizado MySQL para o banco de dados do projeto, pela sua facilidade de implementação e uso extenso no mercado

### Figma
O figma foi utilizado para desenvolver o wireframe distribuição de todas as informações, botões e tabelas do projeto.
